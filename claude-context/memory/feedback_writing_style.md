---
name: Writing style preferences
description: How the user wants all written output formatted, especially prose that may be copied verbatim
type: feedback
---

Never use em dashes (—) or double hyphens (--) anywhere in prose output.

Never use stereotypical AI-sounding expressions. Examples to avoid: "dive into", "let's explore", "it's worth noting", "in conclusion", "it is important to note", "this highlights", "seamlessly", "leverage", "robust", "nuanced", "game-changer", "groundbreaking", "takeaways", filler transitions like "furthermore" or "additionally" when a new sentence works just as well.

Write plainly and directly. Short sentences. No padding.

**Why:** The user sometimes copies written output verbatim into papers or reports. Text that reads as AI-generated undermines credibility.

**How to apply:** Before producing any prose block longer than 2-3 sentences, read it back and strip anything that sounds like a language model trying to sound thorough or enthusiastic. When in doubt, cut the sentence entirely.
